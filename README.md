# Felicia Adekanye — Portfolio

A clean, responsive personal portfolio for Felicia Adekanye, a Computer Science undergraduate focused on data analytics.

## Included
- About section
- Technical skills
- Three selected data/technology projects
- Education and coursework
- Contact links
- Downloadable CV using the uploaded CV document
- Responsive mobile navigation

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your portfolio URL.

## Customise
Replace any project GitHub links with the individual repository URLs once you have them. A professional headshot can be added to `assets/profile.jpg` and inserted into the About section if desired.
